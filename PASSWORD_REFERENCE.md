e # Server Configuration Password Reference

## Quick Access Guide

### Password Format
The password is today's date in **YYYYMMDD** format.

### How to Calculate Today's Password

**Formula:** `YEAR + MONTH (2 digits) + DAY (2 digits)`

## Where to Use

### Tenant Login Screen
- Click the ⚙️ (settings) icon in the center
- Enter today's date as password
- Server URL field will appear
- Edit and save the URL

### Login Screen
- Click the ⚙️ (settings) icon in top-right corner
- Enter today's date as password
- View current server configuration

## Tips

1. **Month and Day must be 2 digits:**
   - ✅ Correct: `20250201` (February 1)
   - ❌ Wrong: `2025021` or `202521`

2. **No separators:**
   - ✅ Correct: `20250213`
   - ❌ Wrong: `2025-02-13` or `2025/02/13`

3. **Use current date:**
   - Password changes daily
   - Yesterday's password won't work
   - Tomorrow's password won't work yet

4. **If you forget:**
   - Just check today's date
   - Format: YYYYMMDD
   - Example: February 13, 2025 → `20250213`

## Security Notes

- Password updates automatically each day
- No hard-coded passwords
- Each POS terminal uses the same logic
- Easy to remember, hard to guess
- Provides adequate security for configuration access
